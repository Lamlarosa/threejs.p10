## Tema Scene: Observasi Lingkungan Alam (Gunung, Laut, Langit)
Scene ini mensimulasikan pulau kecil dengan pencahayaan dinamis dan interaksi komponen alam.

## Cara Menjalankan Project (Lokal)
1. Clone atau download repository ini.
2. Buka folder project menggunakan IDE (VS Code).
3. Jalankan melalui ekstensi Live Server (klik kanan `index.html` -> Open with Live Server).
4. Pastikan terhubung ke internet agar modul dari CDN dapat dimuat.
